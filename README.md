# Embeddings and Semantic Search

## Project Overview
This project implements FAQ search using Keyword Search and Semantic Search.

## Technologies Used
- Python
- NumPy
- Sentence Transformers
- Scikit-learn

## Features
- Created 12 FAQs across HR, IT, and Payroll.
- Generated embeddings using all-MiniLM-L6-v2.
- Implemented cosine similarity using NumPy.
- Implemented semantic search.
- Implemented keyword search.
- Compared both search methods.

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the project:

python main.py

## Sample Queries
- I cannot log in
- when is salary credited
- work from home rules

## Conclusion
Semantic search understands the meaning of a query and provides more relevant results than keyword search when the wording is different.
