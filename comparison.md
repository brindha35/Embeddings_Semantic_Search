
# Keyword Search vs Semantic Search

## Comparison Table

| Query | Keyword Result | Semantic Result |
|---|---|---|
| I cannot log in | 7 results with irrelevant matches | Correct IT account access FAQ ranked first |
| when is salary credited | 3 matching results | Correct salary credit FAQ ranked first |
| work from home rules | 2 results including irrelevant payslip FAQ | Correct work from home FAQ ranked first |

## Where Semantic Search Wins

### 1. I cannot log in
Semantic search identifies the account access FAQ because it understands the meaning of the query rather than relying only on exact keyword matches.

### 2. work from home rules
Semantic search returns the relevant HR FAQ at the top and avoids irrelevant keyword matches.

## Conclusion

Keyword search matches exact words, while semantic search understands the contextual meaning of a query using embeddings and cosine similarity.

Semantic search provides more relevant results for queries with different wording.
